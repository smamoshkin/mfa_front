# Юридические документы FAAPP — комплект и чеклист внедрения

Комплект для запуска faapp.ru по 152-ФЗ и правилам торговли/услуг в РФ (пункт 5.3 TODO).
Составлен под фактическую обработку данных сервиса: email, пароль (хэш), имя тенанта,
API-ключ WB, данные отчётов о продажах, IP/cookie/логи. Серверы — РФ, аудитория — РФ,
трансграничная передача отсутствует.

## Состав комплекта

| Файл | Что это | Куда на сайте |
|---|---|---|
| `01-privacy-policy.md` | Политика обработки ПД (ст. 18.1 152-ФЗ) | `/privacy` |
| `02-consent-pd.md` | Согласие на обработку ПД (чехбокс + полный текст) + отдельное согласие на рассылку | чекбокс в регистрации + `/consent` |
| `03-user-agreement-offer.md` | Пользовательское соглашение — публичная оферта (с блоками подписки `[PAYWALL]`) | `/offer` (или `/terms`) |
| `04-rkn-notification.md` | Инструкция + готовые ответы для уведомления РКН (ст. 22 152-ФЗ) | не публикуется |

## Заполнить перед публикацией (плейсхолдеры `{{...}}`)

Единый список для всех документов:

- {{ФИО ИП / наименование ООО / ФИО физлица}} — оператор;
- {{ИНН}}, {{ОГРНИП/ОГРН}} — после регистрации статуса;
- {{адрес}} — адрес для связи (для ИП допустим адрес регистрации; если не хочется светить домашний — абонентский ящик/адрес аренды, но не выдуманный);
- {{дата публикации}} / редакция от {{дата}};
- {{наименование хостинг-провайдера, регион дата-центра}} — SmartApe, уточнить локацию (РФ!);
- в `04-rkn...`: {{дата фактического начала обработки}} (дата первой регистрации пользователя).

## Порядок действий по времени

**Сейчас (до регистрации ИП/ООО):**
- страницы и чекбоксы можно внедрять;
- публиковать документы с плейсхолдерами НЕЛЬЗЯ — реквизиты оператора обязательны.
  Вариант на переходный период: указать оператором ФИО физлица-владельца (это законно),
  а после регистрации ИП/ООО обновить реквизиты и подать уведомление РКН уже от ИП/ООО;
- товарный знак «FAAPP»: бесплатная предварительная проверка по базам Роспатента/ФИПС
  на сходство в классах МКТУ 09 (ПО), 35 (бизнес-аналитика), 42 (SaaS) — онлайн-сервисами.
  Регистрация не обязательна, но действует принцип «кто первый зарегистрировал»:
  чужая регистрация «FAAPP» в этих классах позволит запретить нам использование
  названия и домена. Заявителем может быть только ИП/ЮЛ (ст. 1478 ГК РФ).

**После регистрации ИП/ООО (до запуска оплаты!):**
1. вписать реквизиты во все документы, проставить даты;
2. опубликовать `/privacy`, `/offer`, `/consent`;
3. подать уведомление РКН (по `04-rkn-notification.md`);
4. назначить себя ответственным за организацию обработки ПД (приказ/решение — внутренний документ);
5. проверить себя в реестре операторов на pd.rkn.gov.ru;
6. подать заявку в Роспатент на регистрацию словесного товарного знака «FAAPP»
   в классах МКТУ 09/35/42 — сразу после уведомления РКН: приоритет знака считается
   с даты подачи. Госпошлины ~35–40 тыс. ₽ при самостоятельной подаче
   (~6–12 мес до свидетельства); поверенный (+30–60 тыс.) — если предварительная
   проверка нашла спорные сходства. Логотип защищается авторским правом и без
   регистрации; комбинированный знак (слово+логотип) — опционально позже.

**При запуске paywall:**
- снять пометки `[PAYWALL]` — разделы 5–6 оферты уже готовы;
- при выборе платёжного посредника (ЮKassa/CloudPayments) — вписать его наименование
  в п. 5.3 оферты и в п. 5.4 Политики (сейчас формулировки нейтральные);
- уведомить РКН об изменении цели обработки («оформление платежей» уже заложено — тогда
  изменений не потребуется, если не появится новых категорий ПД).

**Гигиена (далее):**
- любые изменения целей/категорий ПД → правка Политики + уведомление РКН в течение 10 раб. дней;
- хранить предыдущие редакции документов (внизу Политики это заложено).

## Известные ограничения комплекта

- Комплект — рабочая база, составленная под фактическую архитектуру FAAPP; перед публикацией
  рекомендован экспресс-просмотр практикующим юристом (особенно оферту, если появятся
  нестандартные тарифные условия).
- Разделы оферты про подписку нейтральны к платёжному провайдеру — после выбора шлюза
  уточнить п. 5.3–5.4.
- Самозанятость как статус оператора: допустима для оказания услуг, но при рекуррентных
  платежах и росте сервиса ИП/ООО практичнее; при выборе самозанятости — чеки через «Мой налог».
